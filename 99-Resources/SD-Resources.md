# 📚 System Design Resources

## Start here (in this order)

1. 🎥 **Padhowithpratyush System Design course (L1–L30)** — the syllabus this vault follows. [L1](https://www.youtube.com/watch?v=RNa0Lx4nu80) · [L2](https://www.youtube.com/watch?v=gjwDm_zgj04)
2. 📖 **System Design Interview Vol 1 & 2** — Alex Xu. *Why:* the case-study format interviewers expect.
3. 📖 **Designing Data-Intensive Applications (DDIA)** — Martin Kleppmann. *Why:* the "why" behind everything in modules 03 and 06. Read Ch. 1, 5, 6, 7, 8, 9 at minimum.
4. 🌐 [Hello Interview — System Design in a Hurry](https://www.hellointerview.com/learn/system-design/in-a-hurry/introduction) *Why:* modern framework + deep dives written by ex-FAANG interviewers.
